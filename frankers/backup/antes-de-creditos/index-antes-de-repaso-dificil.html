    🧠 El cerebro de Frankers

    Así piensa Frankers

    Frankers tiene un cerebro hecho de neuronas, como el tuyo pero de mentira. Lee tus palabras y adivina cuál viene después, una por una, y así arma sus frases. Cuanto más lee, más inteligente se pone.

    📈 ¿Cuánto acierta?

    La línea sube y baja mientras aprende. Cuanto más arriba, mejor: quiere decir que adivina mejor la palabra que sigue.

    📚 Palabras y significados

    Frankers conoce … palabras, pero solo sabe qué significan …. Acá le podés enseñar.

      🏋️

      Enseñale

      Frankers lee un montón de textos y practica adivinar la palabra que sigue. Cada vez que se equivoca, sus neuronas se arreglan un poquito. Así aprende.

      🧩

      Hacela más grande

      Le agrega 8 neuronas nuevas. Con más neuronas puede acordarse de más cosas. No se olvida de nada: las neuronas nuevas empiezan calladitas y aprenden cuando la enseñás.

      💬

      Probá cómo habla

      Escribile algo y mirá qué frase inventa, palabra por palabra.

        📄

        Dale algo para leer

        Pegá un cuento o un texto. Frankers lo lee y lo guarda en sus neuronas (si no tiene malas palabras ni cosas falsas).

        🤔 ¿Cómo piensa una red neuronal?

        1. Lee tus palabrasCada palabra se convierte en números, porque las neuronas solo entienden números.
        2. Las neuronas se pasan los númerosCada neurona suma lo que le llega, y si es mucho, se prende. Las que se prenden le pasan el mensaje a las de la derecha.
        3. Adivina la palabra que sigueAl final, cada palabra que sabe tiene un puntaje. Elige una de las que tienen más puntos, y repite todo para la siguiente.
        4. Aprende de sus erroresCuando entrena, mira si adivinó bien. Si no, ajusta un poquito cada conexión para acertar la próxima vez. ¡Por eso hay que enseñarle!

                        🔑 Modo creador

                        Esto es solo para Franco. Con el modo creador, podés publicar el cerebro entrenado en GitHub, así todos tienen a Frankers con lo que aprendió.

                        1. Entrá a github.com/settings/personal-access-tokens/new.
                        2. Nombre: Frankers. Expiración: la que quieras.
                        3. En Repository access elegí Only select repositories → franco-magia.github.io.
                        4. En Permissions → Repository permissions → Contents poné Read and write.
                        5. Tocá Generate token, copialo y pegalo acá abajo.
