    🧠 Lo que me enseñaron

      🔑 Modo creador

      Esto es solo para Franco. Con el modo creador aparece el botón Enseñar, y lo que le enseñes se guarda en GitHub para todos.

      1. Entrá a github.com/settings/personal-access-tokens/new.
      2. Nombre: Frankers. Expiración: la que quieras.
      3. En Repository access elegí Only select repositories → franco-magia.github.io.
      4. En Permissions → Repository permissions → Contents poné Read and write.
      5. Tocá Generate token, copialo y pegalo acá abajo.

      ✅ El modo creador está activado en esta compu. Lo que le enseñes a Frankers se publica para todos.
